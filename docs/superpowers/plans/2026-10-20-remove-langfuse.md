# Remove Langfuse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Langfuse from `phantom-ink`, `phantom-router` and `phantom-platform`, and delete phantom-ink's deprecated `reflex/` subtree.

**Architecture:** Almost all of this is deletion of code that is already dead — OpenSearch replaced Langfuse by operator decision on 2026-10-19/20. There is exactly one piece of real engineering: `phantom-router`'s `llm/tracing.py` goes through the Langfuse SDK and is used by three live call sites, so its internals are reimplemented on `llm/otel.py`'s OTel-native primitives **while keeping its public signatures unchanged**, which leaves every caller untouched.

**Tech Stack:** Go 1.25 + Wails 2 + Svelte 5 (phantom-ink app), Python 3.11 + FastAPI + pytest + ruff (brainbox, phantom-router), Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-20-remove-langfuse-design.md`

## Global Constraints

- **IaC is out of scope.** Leave the Langfuse entries in `phantom-router/ansible/` and `phantom-ink/brainbox/ansible/` exactly as they are. `neverprepared-iac` is already clean.
- **Never commit to `main`.** Each phase is its own branch and PR.
- **`phantom-ink` branch for phases B and E: `chore/remove-langfuse`** (already exists, already carries the spec and this plan).
- `app/frontend/dist/` is a **build artifact** that is committed. Never hand-edit it; it is regenerated by `just app-build` / `wails build`.
- `app/frontend/wailsjs/` is **generated from the bound `*App` methods**. Deleting a bound method requires regenerating and committing it, or the method appears to still exist.
- Verification commands, by tree: phantom-ink app — `cd app && go test ./... -race` and `cd app/frontend && npm run check && npm test`; phantom-ink brainbox — `just bb-test` and `just bb-lint`; phantom-router — `uv run pytest` and `uv run ruff check src/`.
- The final `grep -rli langfuse` will legitimately still hit the two ansible trees, the dated as-built log, and this plan plus its spec. That is expected, not a miss. `ADR-002` is **not** on that list — it was found by the *reflex* grep and never mentioned Langfuse, so a Langfuse hit there would be a real miss.

## Ordering constraint the spec got wrong

The spec says the reflex deletion's order "does not matter" relative to the Langfuse removal. **It does.** `docker/brainbox/Dockerfile.researcher:16-17` copies two scripts *out of* `reflex/plugins/reflex/scripts/`:

```dockerfile
COPY --chown=developer:developer reflex/plugins/reflex/scripts/langfuse-hook.sh /home/developer/.claude/hooks/langfuse-hook.sh
COPY --chown=developer:developer reflex/plugins/reflex/scripts/langfuse-trace.py /home/developer/.claude/hooks/langfuse-trace.py
```

Deleting `reflex/` before removing those `COPY` lines breaks the researcher image build. Task 6 removes them; Task 8 deletes the subtree. **Task 6 must land before Task 8.**
