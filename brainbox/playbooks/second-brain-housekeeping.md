# Second Brain Housekeeping

Audits the Obsidian vault and takes action: archives completed projects, moves misplaced entries, deduplicates resources, and cleans stale data. This is not a review — it is a cleanup. Make changes, don't just recommend them.

- [ ] Get vault overview: call `memory_stats()` and `memory_list(limit=100)`. Report total count and breakdown by PARA category. Then proceed to clean up each category.
- [ ] Clean `projects/`: for each entry, check if the work is done (PR merged, ratchet completed, task finished). If done, archive it now with `memory_archive(id="<id>")`. If the entry is empty or broken, delete it with `memory_delete(id="<id>", confirm=true)`. Only keep entries where work is genuinely still in progress. Report what you archived and what you kept.
- [ ] Clean `areas/`: for each entry, check if it's really an ongoing responsibility. If it's a one-time finding or reference doc, move it: call `memory_store()` with the same content but `para="resources"`, then `memory_archive(id="<old_id>")` the original. If it's stale and no longer relevant, archive it directly. Working-memory-log fragments from completed ratchet runs should be archived. Report actions taken.
- [ ] Clean `resources/`: find duplicates (similar titles or overlapping content). For each duplicate set, keep the most complete/recent entry and archive the rest with `memory_archive(id="<id>")`. Report which were kept and which were archived.
- [ ] Run `memory_cleanup(target="stale", action="list")`. For each stale candidate: if genuinely outdated, archive it with `memory_cleanup(target="stale", action="archive")`. If still relevant, extend its TTL with `memory_update(id="<id>")`. Do not leave stale entries unresolved.
- [ ] Store a housekeeping summary with `memory_store(title="housekeeping/<date>", content="## Actions Taken\n- Archived: <n> entries\n- Moved: <n> entries\n- Deleted: <n> entries\n- Kept: <n> entries\n\n### Details\n- ...", para="resources", tags=["housekeeping", "maintenance"])`.
